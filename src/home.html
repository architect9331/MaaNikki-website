支持哪些平台？

目前只支持 Windows 10 / 11 x64 的 PC 客户端。地图标记和共鸣记录使用美鸭梨国服账号。

能一边跑一边用电脑吗？

跑路线要占用前台输入，切走游戏会暂停，切回来继续。所以跑日常时最好让电脑歇一会儿。探索辅助里的部分功能可以在后台运行，详见手册。

提示截图尺寸不符怎么办？

游戏实际画面需要保持 16:9（窗口若被任务栏挤压可改无边框或更小的 16:9 窗口）；若开启超分辨率 TSR 后比例仍异常，切换为 DLSS、XeSS 或 TAA 再试。

全收集会不会把我想留的吃掉？

没锁定的会被用掉：升级时一键放入五星及以下素材，刷完还会分解四星及以下的闪光。想留的请先锁上。

出问题了找谁？

在软件里「导出日志」，说说什么时候、在做什么，发到 QQ 群或 GitHub Issue。
